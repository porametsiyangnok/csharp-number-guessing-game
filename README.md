C# Number Guessing Game

A simple C# console application where the player has to guess a randomly generated number.

How it works
- The program generates a random number between 1 and 10
- The player enters guesses via the console
- The program gives feedback if the guess is too high or too low
- The game counts the number of attempts until the correct number is guessed

Technologies
- C#
- .NET Console Application

How to run

bash
dotnet run
